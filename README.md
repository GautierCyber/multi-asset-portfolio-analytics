# Multi-Asset Portfolio Analytics

Python-based project for multi-asset portfolio construction, backtesting and risk analytics.

## Status

Work in progress.

## Objectives

The project aims to implement and compare several portfolio construction approaches:

- Equal Weight
- Global Minimum Variance
- Maximum Sharpe Ratio
- Equal Risk Contribution / Risk Parity

The platform will progressively include:

- market data processing and validation
- portfolio optimisation under constraints
- walk-forward backtesting
- transaction costs and portfolio turnover
- performance and risk analytics
- portfolio risk contribution analysis
- interactive visualisation

## Tech Stack

- Python
- NumPy
- pandas
- SciPy
- Matplotlib
- Streamlit
